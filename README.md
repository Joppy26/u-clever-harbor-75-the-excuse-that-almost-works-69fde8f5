A tiny Python program that writes the one line a gamer texts the boss to
skip work on GTA 6 launch week: a single, hurried, almost-believable excuse
with one concrete detail — a front door lock that jammed overnight and a
locksmith who can't come till noon.

Run it with `python3 main.py`. It writes `entry.txt` into the directory
named by `MAKEFUN_OUTPUT_DIR`, or `/output` by default. The output is
deterministic: every run writes the exact same bytes.
